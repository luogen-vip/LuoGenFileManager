# 罗根文件管家 (LuoGen File Manager)

一个全类型安卓文件管理器：图片 / 视频 / 音频 / 文档 / 应用 / 压缩包 / 收藏 / 下载 / 回收站 / 加密保险箱 / 清理。

## 功能

- 首页分类：图片、视频、音频、文档、应用（已安装 + APK）、压缩包、收藏、下载、回收站、加密保险箱、清理
- 实时预览搜索（每个分类内独立，返回后保留搜索状态）
- 排序：时间 / 大小 / 名称，升降序
- 多选：分享、复制、移动、删除、重命名（支持批量按规律重命名）、收藏、压缩
- 回收站：还原、彻底删除
- 图片查看：左右滑动、信息、路径复制/跳转
- 视频 / 音频播放（media3 ExoPlayer），音频封面
- 文档预览与文本编辑、PDF 阅读
- 压缩包识别与解压、新建压缩
- 加密保险箱：数字密码 / 图案密码 / 问答密码，AES-256-GCM 真实加密，存在应用私有目录
- 清理：分类占用、垃圾文件建议清理、应用卸载

## 编译

GitHub Actions 自动构建（`.github/workflows/build.yml`），产物为 debug APK。

本地构建：

```bash
gradle assembleDebug
```

## 说明

本项目完全真实实现，非 UI 模拟。部分格式支持依赖系统解码器（视频/音频）与内置解压库（zip/tar/gz/bz2/xz/7z）。
